# 📊 To-Let Globe — Power BI Dashboards

## 📌 Project Overview

This repository contains **Power BI dashboards developed during my Data Analyst Internship at To-Let Globe**.

The project focused on transforming raw business data into interactive visual reports for **LinkedIn performance analysis, city-wise property listing analysis, and intern performance tracking**.

The dashboards were designed to make performance trends easier to understand and support structured, data-driven decision-making.

---

## 🎯 Project Objectives

* Track LinkedIn content performance using key engagement metrics.
* Analyze property listing performance across different cities.
* Compare social media engagement across locations.
* Monitor intern-wise content performance and productivity.
* Transform raw data into clear and meaningful visual insights.
* Develop reusable dashboards for structured performance monitoring.

---

## 🔎 Dashboards Developed

### 💼 1. LinkedIn Performance Dashboard

The dashboard organizes LinkedIn performance metrics such as **impressions, clicks, reactions, shares, followers, visitors, and engagement indicators**.

**Key Analysis:**

* Monthly and yearly performance
* Content engagement
* Impressions and clicks
* Reactions and shares
* Follower growth
* Visitor activity
* High-performing content

---

### 🏠 2. Property Listing Dashboards — City-Wise

Property listing data was analyzed across **Mumbai, Hyderabad, Gurgaon, and Kolkata** to understand location-specific performance.

Separate dashboards were developed for each city.

**Key Analysis:**

* City-wise listing performance
* Impressions and clicks
* Reactions and engagement
* Property-related performance patterns
* Location-specific comparison

---

### 👥 3. Intern Performance Tracking Dashboard

A KPI-based dashboard was developed to monitor intern-wise content performance and activity.

**Key Analysis:**

* Intern-wise performance
* Number of posts
* Total impressions
* Engagement levels
* Performance against expected activity
* Productivity comparison
